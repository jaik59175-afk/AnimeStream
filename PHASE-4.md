# AnimeStream Phase 4

Visual redesign focused on a more premium, cinematic anime-platform feel.

## Included
- Phase 3 functionality
- Compact episode range selector using a native dropdown instead of a wall of range buttons
- 25-episode pagination within each 100-episode range
- Cinematic featured hero
- Refined poster cards and hover states
- Improved anime details layout
- Cleaner sidebar/header
- Continue Watching progress treatment
- Refined watch/player screen
- Responsive mobile layout
- Local Library + History
- Provider-ready messaging without implementing unauthorized stream extraction

## Run
npm install
npm run dev
